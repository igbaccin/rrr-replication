# Deposited results

`corrected/` is the accepted vlm.2.1 analytical and exhibit bundle. Its
manifest records 941 writer-stage attempts, of which 907 produced reviews and
34 ended in writer failure, together with 300 independent baselines and 1,184
pre-writer terminal outcomes.

## Current local battery

`local_battery_vlm_2_1/` preserves the deposited local-model battery. It contains 941
writer-stage attempts generated by vlm.2.0 and processed by the deterministic
vlm.2.1 citation normalizer.

The deposited generation outcomes are:

- 887 successful runs
- 20 checker-flagged runs
- 34 writer failures
- 907 produced review files

In the original deposited generation, the reference model, Mistral Small 24B,
succeeds in 653 of 660 writer-stage attempts. Its 15 non-clean successful runs
all belong to the validation-disabled condition. Across validation-enabled
conditions, 553 reviews were released and all 553 are free of E1 through E5
under the automated checker. The main condition contains 99 released reviews
in 100 attempts.

`summary.json`, `per_run.csv`, and `conditions/*.json` contain the deposited
counts. `reviews_raw/` contains the 907 generated review files.
`REVIEWS_README.md` explains the normalization reproduction and denominator
rules.

## Current paper artifacts

`local_battery_vlm_2_1/exhibits/` preserves the first vlm.2.1 table and figure bundle. Its
analytical source passes all 21 checks, and its artifact manifest records ten
additional passing checks.

The F5 model table and graph use all 105 attempted runs per ladder model. They
combine writer-stage results with the preserved pre-writer outcomes and display
writer failures as a separate category. Every row accounts for every attempt.

`corrected/` contains the later accepted analytical and exhibit generation. It
records 40,586 parsed citations across 907 produced reviews, 34 writer failures,
and the 99-clean Phase A result.

`external_comparisons/claude_code/` contains the completed direct Claude Code
