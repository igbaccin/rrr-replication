# Deposited results

## Current local battery

`local_battery_vlm_2_1/` is the accepted local-model battery. It contains 941
writer-stage attempts generated by vlm.2.0 and processed by the deterministic
vlm.2.1 citation normalizer.

The accepted outcomes are:

- 887 successful runs
- 20 checker-flagged runs
- 34 writer failures
- 907 produced review files

The reference model, Mistral Small 24B, succeeds in 653 of 660 writer-stage
attempts. Its 15 non-clean successful runs all belong to the
validation-disabled condition. Across validation-enabled conditions, 553
reviews were released and all 553 are free of E1 through E5 under the automated
checker. The main condition contains 99 integrity-clean reviews in 100
attempts.

`summary.json`, `per_run.csv`, and `conditions/*.json` contain the deposited
counts. `reviews_raw/` contains the 907 generated review files.
`REVIEWS_README.md` explains the normalization reproduction and denominator
rules.

## Current paper artifacts

`local_battery_vlm_2_1/exhibits/` is the accepted table and figure bundle. Its
analytical source passes all 21 checks, and its artifact manifest records ten
additional passing checks.

The F5 model table and graph use all 105 attempted runs per ladder model. They
combine writer-stage results with the preserved pre-writer outcomes and display
writer failures as a separate category. Every row accounts for every attempt.

`corrected/` preserves the earlier v17 analytical and exhibit bundle for
historical comparison. It is no longer the accepted paper-artifact generation.

## Reproduction material

`replay_inputs/` contains the compressed frozen ledgers used for corrected
writer reproduction. `rebuild_inputs/pre_correction_snapshot/` contains the
label and baseline inputs required by the exhibit builder.

`external_comparisons/claude_code/` contains the completed direct Claude Code
comparisons. `external_comparisons/notebooklm_pilot/` remains a provisional
single-run pilot.
