# Raw reviews and reproduction

`reviews_raw/<batch>/<condition>/<run>.md` are the **941 reviews as generated by
vlm.2.0** (887 with a review file; 34 writer-failures produced none, so 907
files). These are the exact artifacts the vlm.2.1 citation normalizer was applied
to.

`vlm.2.1` differs from `vlm.2.0` only by a deterministic final-assembly pass that
canonicalises internal doc-ids leaked into prose (`(Doc_Year)`,
`(paper Doc_Year, page N)`, `(Doc_Year (Author Year, p.N))`). It runs downstream
of every model call, so applying it to these frozen reviews is equivalent to
having generated with it: verified 0 prose-content changes and 0 checker
regressions across all 941 runs.

To reproduce the 41 checker-failure -> success reclassifications:

```bash
pip install "git+https://github.com/igbaccin/rrr-replication.git"
python results/local_battery_vlm_2_1/reproduce_normalization.py
```

The transform is deterministic and gated by each run's allowed documents
(`allowed_docs.json`). `per_run.csv` records the before/after outcome per run in
the columns `outcome_asrun` (vlm.2.0) and `outcome` (vlm.2.1); the 41 rows where
`outcome_asrun = checker_failed` and `outcome = success` are the reclassifications.

DENOMINATORS: per-model counts are writer-stage (only attempts that reached the
writer entered this battery). Attempts that refused or failed earlier are the
separate 1,184 pre-writer terminals; end-to-end model rates recombine the two.
